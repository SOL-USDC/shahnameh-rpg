# Shahnameh RPG (Work in Progress)

A top-down, Zelda-style action RPG built in Python and Pygame, based on the Shahnameh, the Persian *Book of Kings*.

## About
The game follows the hero Rostam and is planned as multiple chapters across the epic's eras. I started from a Pygame RPG tutorial and am building it out with my own story, characters, art, and world.

## Built With
- Python
- Pygame
- AI-assisted pixel art and a custom Shahnameh color palette

## How to Run
1. Install Python 3 and Pygame: `pip install pygame`
2. Run: `python code/main.py`

## Status
In progress. Currently working on the player, map, and core game systems.
